# PWA Demandas

App para acompanhar demandas pelo celular. É um PWA instalável no Android que funciona offline.

- HTML, CSS e JavaScript puros, sem framework e sem etapa de build.
- Os dados ficam salvos só no aparelho. Não há servidor.
- Tem exportação e importação em JSON para backup.

> Este repositório é público e contém apenas dados de exemplo.
